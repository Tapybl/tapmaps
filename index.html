Add your Google Maps API key

This app needs a Google Maps JavaScript API key to load. Open index.html and replace YOUR_API_KEY_HERE near the bottom.

  1. Go to Google Cloud → Maps
  2. Enable Maps JavaScript API (and Street View is included).
  3. Create an API key and paste it into the file.
